Native CopyQ history

The installed Clipboard History desktop entry opens the standalone native history panel. This Web entry declares no MCP tools and cannot load, restore, delete or clear history.

History read

clipboard.read:history allows the native panel's policy-checked history display. It is not clipboard.read:selection.

History changes

The native panel checks history grants for restore, delete and clear. This Web page has no history execution bridge and cannot borrow the Clipboard Manager identity.
